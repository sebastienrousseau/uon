# Release Notes

This directory stores repo-local release notes in the same format used for GitHub releases.

## Convention

- GitHub release title: `uon X.Y.Z`; signed tag `vX.Y.Z` with the message `uon vX.Y.Z`
- Sections: `## Highlights ⭐️` (written here), then `## What's Changed`, `## Checksums` and `**Full Changelog**`, which the release adds from the pull requests and assets
- Tone: short, factual, release-specific, and no em dashes
