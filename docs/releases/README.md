# Release Notes

This directory stores repo-local release notes in the same format used for GitHub releases.

## Convention

- Title: `vX.Y.Z — Subtitle`
- Sections: `## What's New`, `#### Verification` when relevant, and `## Full Changelog`
- Tone: short, factual, and release-specific
