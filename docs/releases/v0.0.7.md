## Highlights ⭐️

* **Every SSH key is hooked**: `install_target.sh` now puts the `uon_verifier.py` forced command on every `authorized_keys` entry, whatever its type or options. ECDSA P-384 and P-521 keys, FIDO `sk-*` keys, keys with options in front and indented lines were left unhooked before, so their holders got a shell without the FIDO2-signed approval uon enforces (GHSA-9867-mvqf-22gp).
* **uon.me is the project's home**: the site deploys with the GitHub Pages actions and the package metadata names https://uon.me/.
* **SPDX licence expression**: `pyproject.toml` declares the licence as an SPDX expression.
