## Highlights ⭐️

* **No vulnerable dependency resolves**: All 102 open Dependabot alerts are cleared, 14 of them critical. Pillow, starlette, anyio, idna, python-dotenv and certifi have floors at their first versions without a published advisory, in both `poetry.lock` and `uv.lock`; russh moves to 0.64.1 and pageant to 0.2.4. `cargo audit` reports nothing.
* **No RSA**: russh is built without its `rsa` feature, removing the `rsa` crate and its unfixed timing advisory (RUSTSEC-2023-0071). uon uses ed25519 and ECDSA keys only; an RSA key in ssh-agent is skipped, and a server needs an ed25519 or ECDSA host key.
* **ZSP broker in Rust**: The broker's hot path moves from Python into the Rust core, and the broker now builds on macOS as well as Linux.
* **Host certificates refused**: With russh 0.64 a server can present a host certificate. uon cannot validate one, so it refuses it; plain host keys keep their trust-on-first-use pinning.
