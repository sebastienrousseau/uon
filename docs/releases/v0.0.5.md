# v0.0.5

## Summary

This release closes the Dependabot-related branch failures and restores all CI jobs to green.

## Included Changes

- update the CI workflow to install the project with the `dev` extra on clean runners
- add a typed stub for the Rust extension boundary in `uon.core`
- fix Ruff and MyPy failures across Python modules and tests
- replace hanging FastAPI `TestClient` route tests with direct request-based tests
- align the eBPF monitor test with the current implementation
- fill the remaining coverage gaps and exclude the untested `uon.ux` Textual package from coverage accounting

## Verification

- `poetry run mypy src/`
- `poetry run pytest -q`
