# v0.0.5 — CI Stability and Security Fixes

## What's New

### CI Stability and Security Fixes

`uon` restores the CI pipeline to green, resolves dependency and security failures, and tightens the Python and Rust verification boundary.

#### Major fixes

| Area | Description |
|---|---|
| CI workflow | Clean runners now install the `dev` toolchain needed for linting, typing, and tests. |
| Dependency remediation | Vulnerable `russh`, `cryptography`, and `pygments` paths were updated across Python and Rust artifacts. |
| Type and lint hygiene | Ruff and MyPy failures were fixed, and the Rust extension boundary gained typed stubs. |
| Test reliability | Hanging FastAPI test coverage was replaced with direct request-based tests and stale expectations were aligned. |
| Coverage enforcement | The enforced suite returned to 100% coverage. |

#### Verification

- `poetry run ruff check .`
- `poetry run mypy src/`
- `poetry run pytest -q`

Result:

- 185 tests passed at release time
- 100.00% coverage at release time
